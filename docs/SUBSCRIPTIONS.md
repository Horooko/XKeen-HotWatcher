# Подписки и границы конвертера

## Вход

Поддержаны UTF-8 строки URI, разделённые переводом строки, либо Base64 всего такого
списка (обычный/URL-safe алфавит, с padding и без). Пустые строки и строки-комментарии
`# ...` пропускаются. Размер ответа ограничен 2 MiB, одна строка — 32 KiB, число уникальных узлов — `max_nodes`.

Распознанные URI `trojan://`, `vmess://`, `ss://`, `ssr://`, `hysteria2://`, `hy2://`
пропускаются и учитываются в счётчике. Это не оценка безопасности этих протоколов,
а **намеренное ограничение данного продукта VLESS**.

Clash YAML, sing-box JSON, Karing provider/config JSON, JSON-массивы профилей и готовый
Xray JSON **не принимаются**. Укажи отдельный URI/Base64 endpoint твоего сервиса.
Программа не исполняет и не импортирует произвольную маршрутизацию/файлы из подписки.

## Поддержанные VLESS

| Параметр | Поддержка |
|---|---|
| Учётная запись | UUID в каноническом формате `8-4-4-4-12` |
| Порт | Явно указан, 1..65535 |
| `encryption` | `none` или отсутствует |
| `security` | Явно `reality`; `tls` только при `allow_tls_nodes: true` |
| `type` | `tcp`/`raw`, `ws`, `grpc`, простой `xhttp` |
| `flow` | Пусто или `xtls-rprx-vision`; Vision только на TCP/raw |
| Reality | `sni`/`serverName`, `fp`, `pbk`, `sid`, необязательный `spx` |
| TLS | SNI, fingerprint, `alpn`; `allowInsecure` не поддерживается |
| WS | `path`, `host` |
| gRPC | `serviceName`, `authority` или `host`, `mode=gun/multi` |
| XHTTP | `path`, `host`, `mode=auto/packet-up/stream-up/stream-one` |
| `headerType` | Только отсутствует или `none` |
| `#name` | Метаданные, не определяют протокол или идентичность ключа |

Reality public key проверяется на 32 байта после Base64URL, short ID — на чётное число
hex-символов до 16. TLS без SNI использует адрес сервера; для Reality SNI обязателен.
Значения URI percent-decode выполняются один раз стандартным URL-парсером.

## Строгое поведение

Неизвестный/повторённый параметр VLESS, неподдержанный транспорт, шифрование VLESS,
неоднозначная настройка или неверный UUID **отклоняют весь update**, а не тихо удаляют
этот узел из рабочего пула. Уже работающие конфигурации остаются.

Например, advanced XHTTP `extra`, `downloadSettings`, цепочки `dialerProxy`, transport
obfuscation, custom certificates, `packetEncoding`, VLESS Encryption и новые flow/seed
не реализованы в 0.1. Не удаляй такие параметры вслепую ради прохождения парсера: они
могут быть нужны серверу. Нужен поддерживаемый профиль или расширение конвертера с тестами.

В сгенерированном Xray JSON используются проверяемые `vnext/users` и `streamSettings`.
Совместимость фактической сборки проверяется её собственным `xray run -test` и затем
пробой кандидата; принятие JSON само по себе не доказывает UDP-совместимость.

## Источник выдаёт редирект

Редиректы загрузки подписки запрещены, в том числе HTTPS→HTTPS. В настройке должен быть
конечный URL с HTTP 200. Это исключает неожиданную передачу персонального URL/токена
другому адресу. Авторизация через отдельные HTTP-заголовки в этой версии не реализована.
